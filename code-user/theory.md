# Orange pi 5 plus
## Что такое Orange pi 5 plus
- Orange Pi 5 Plus — это мощный одноплатный микрокомпьютер, представляющий собой полноценный мини-ПК на одной плате.
# Характеристики
1) Процессор (SoC): 8-ядерный Rockchip RK3588 (4 ядра Cortex-A76 с частотой до 2,4 ГГц и 4 ядра Cortex-A55).
2) Графика (GPU): ARM Mali-G610 с поддержкой 3D и видео высокого разрешения.
3) Оперативная память: Варианты от 4 ГБ до 32 ГБ LPDDR4/4x.
4) Накопители: Слот для microSD, разъём для eMMC-модулей и полноценный слот M.2 2280 для быстрых SSD NVMe.5) Интерфейсы: Порты USB 3.0, USB 2.0, USB Type-C, два порта HDMI, два сетевых порта (2.5G Ethernet) и поддержка беспроводных модулей Wi-Fi/Bluetooth. 
# Для чего используется:
1) Создание домашнего сервера или медиацентра.
2) Запуск проектов умного дома и интернета вещей (IoT).
3) Задачи, связанные с искусственным интеллектом и машинным обучением (благодаря встроенному NPU).
4) Обучение программированию и использование в качестве недорогого десктопного компьютера для повседневных задач.
   ## Накопители и их сравнение на Orange Pi 5 plus
  | Характеристика | **microSD** | **eMMC** | **NVMe SSD** |
|:---|:---|:---|:---|
| **Скорость (теория)** | До 100 МБ/с | До 400 МБ/с | До 5000+ МБ/с |
| **Реальная скорость** | 20–90 МБ/с | 60–250 МБ/с | 460–1400 МБ/с |
| **Как подключить** | В слот на плате | В специальный слот (модуль) | В слот M.2 на плате |
| **Сложность установки** | Самая простая | Средняя | Сложная |
| **Нужен ПК с Windows?** | Нет | Да (RKDevTool) | Да (для SPI) |
| **Нужна прошивка SPI?** | Нет | Нет | **Да, обязательно** |
| **Цена** | Дешёвая | Средняя | Дорогая |

# Плюсы и минусы MicroSd:
| Плюсы | Минусы |
|:---|:---|
| Самый простой способ | Самая низкая скорость |
| Не нужен ПК с Windows | Система работает медленнее |
| Не нужно прошивать SPI | Карта может изнашиваться |
| Легко менять систему | Не подходит для тяжёлых задач |
| Дёшево | Может «вылетать» при плохом контакте |
# Порядок по скорости:
1) NVMe SSD — максимальная скорость
2) eMMC — средняя скорость
3) microSD — самая низкая
   
# Плюсы и минусы eMMС:
| Плюсы | Минусы |
|:---|:---|
| Быстрее microSD | Нужно покупать модуль |
| Надёжнее карты | Сложнее прошивать |
| Встроен в плату | Нужен ПК с Windows |
| Не занимает слот M.2 | Не такой быстрый, как NVMe |

# Плюсы и минусы NVme SSD:
| Плюсы | Минусы |
|:---|:---|
| **Максимальная скорость** | **Требует прошивки U-Boot в SPI** |
| Быстрая загрузка | Дороже |
| Идеален для тяжёлых задач | Сложнее в установке |
| Большой объём | Могут быть проблемы совместимости |

# Что такое SPI:
- SPI (Serial Peripheral Interface) — это маленькая микросхема памяти на плате Orange Pi, в которой хранится загрузчик (U-Boot). Это «стартовый» код, который запускается самым первым при включении платы.
