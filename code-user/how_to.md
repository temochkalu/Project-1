##Как перепрошить Orange Pi 5 plus
 # Прошивка через microSD:
MicroSD — это маленькая карта памяти, которую используют в телефонах, камерах, планшетах и одноплатных компьютерах (вроде Orange Pi). Она хранит данные: фото, видео, музыку, операционные системы. 
 
# Объемы microSD
| Объём | Для чего хватит |
|:---|:---|
| 8 ГБ | Минимум для системы |
| 16 ГБ | Небольшая система |
| 32 ГБ | Комфортно для Linux |
| 64 ГБ | С запасом |
| 128 ГБ+ | Много данных |
# Классы скорости
| Класс | Скорость | Для чего |
|:---|:---|:---|
| Class 4 | 4 МБ/с | Медленно, не рекомендуется |
| Class 10 | 10 МБ/с | **Минимум для системы** |
| UHS-I (U1) | 10 МБ/с | Хорошо |
| UHS-I (U3) | 30 МБ/с | Отлично |
# Что нужно для прошивки Orange Pi
Купи microSD — Class 10, 16–32 ГБ.

1) Вставь в картридер — подключи к компьютеру.

2) Запиши образ системы через balenaEtcher.

3) Вставь карту в Orange Pi — включи питание.

4) Система загрузится с карты.
 ## Пошаговая инструкция для прошивки через eMMC
0) Скачиваем образ ОС Armbian Orange Pi 5 Plus(допустим Ubuntu 24.04)
1) Переходим на официальный сайт и заходим на Download->Official Tools
2) Попадаем в гугл диск и заходим в папку Android and Linux image...
3) Скачиваем папку и 2 архива
4) Скачиваем DriverAssitant
5) Запускаем RKDevtool
6) Подключаем USB кабель от компа в порт Tupe-C--Tupe-A и зажимаем кнопку мaskrom
7) Удерживая кнопку подключаем питание в плату(после загорания красного индикатора отпускаем кнопку)
8) Возращаемся в RKDevtool нажимаем ПКМ в любом месте таблицы и выбираем предпоследний пункт
9) Идем в папку MinniLoader  и выбираем файл заканчивающийся на emmc.cfg
10) В появившихся двух строках нажимаем на последний столбец  первой строки и выбираем MiniLoaderAllbin
11) Во второй строке выбираем скаченный образ ОС и распоковываем(ПКМ->доп параметры->7 zip->распоковать Armbian) и переименовываем юолее сокращенно
12) Рапокованный образ выбираем для последнего стобца во второй строке.
13) Ставим галочку и нажимаем на первую кнопку снизу
14) Если плата не запускаеться стоит перезагрузить SPIFlash(D RKDevtool переходим в 3 закладку в свободном поле Boot выбираем файл MiniLoaderAllbin и нажимаем кнопку после пустого поля. Выбираем 5 пункт SPINOR  и неажимаем на кнопку в 4 стобце 2 строке. Нажимаем кнопку в 3 столбце 4 строке)
